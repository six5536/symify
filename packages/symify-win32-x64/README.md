# @six5536/symify-win32-x64

Prebuilt `symify` binary for **win32-x64**. This is an internal artifact of
[`symify`](https://www.npmjs.com/package/symify), which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `symify` instead.
