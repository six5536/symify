# @six5536/symify-darwin-arm64

Prebuilt `symify` binary for **darwin-arm64** (macOS, Apple silicon). This is an
internal artifact of [`symify`](https://www.npmjs.com/package/symify), which
installs it automatically as an optional dependency on a matching machine. Don’t
depend on it directly; install `symify` instead.
