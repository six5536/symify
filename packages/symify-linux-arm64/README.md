# @six5536/symify-linux-arm64

Prebuilt `symify` binary for **linux-arm64**. This is an internal artifact of
[`@six5536/symify`](https://www.npmjs.com/package/@six5536/symify) — npm installs
it automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `@six5536/symify` instead.
