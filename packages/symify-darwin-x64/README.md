# @six5536/symify-darwin-x64

Prebuilt `symify` binary for **darwin-x64** (macOS, Intel). This is an internal
artifact of [`symify`](https://www.npmjs.com/package/symify), which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `symify` instead.
